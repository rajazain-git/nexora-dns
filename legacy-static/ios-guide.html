Wi-Fi Configuration Scope

Manual DNS configuration in iOS applies specifically to the selected Wi-Fi network. If you want DNS optimization enabled system-wide across both Wi-Fi and Cellular Mobile Data (4G/5G), switch to the DNS Profile tab above.

1

Open Settings

From your iPhone or iPad home screen, locate and open the standard Settings app.

Screenshot Placeholder iPhone Settings Home • 300 × 500
2

Tap Wi-Fi

In the main Settings menu, tap the Wi-Fi section near the top of the screen to view available connections.

Screenshot Placeholder Wi-Fi Settings Page • 300 × 500
3

Tap the (i) Icon

Find your active connected Wi-Fi network (marked with a checkmark) and tap the blue circular ⓘ (Info) icon on the far right.

Screenshot Placeholder Network Details View • 300 × 500
4

Tap Configure DNS

Scroll down to the bottom of the network configuration screen and tap on Configure DNS (which is currently set to 'Automatic').

Screenshot Placeholder Configure DNS Row • 300 × 500
5

Select Manual

Change the DNS mode from Automatic to Manual. The existing DNS servers list and an 'Add Server' option will appear.

Screenshot Placeholder Manual Toggle Selected • 300 × 500
6

Remove Existing Servers

Tap the red minus icon (-) next to each existing DNS address, then tap Delete to clear out your ISP's default DNS addresses.

Screenshot Placeholder Clear Default DNS Rows • 300 × 500
7

Add DNS Servers

Tap Add Server and enter your assigned Primary DNS. Tap Add Server again and enter the Secondary DNS. Use your assigned addresses:

8

Tap Save

Tap Save in the upper right-hand corner. Your iPhone or iPad will now immediately begin routing queries through your premium DNS servers!

iOS Troubleshooting

Quick fixes for common issues when setting up DNS on Apple devices.

Double-check the DNS addresses to ensure there are no accidental spaces or typing errors. If the issue persists, revert Configure DNS to 'Automatic' and contact our WhatsApp support team with your order TID for instant server status verification.

Make sure you are downloading the profile using Safari. Third-party iOS browsers (Chrome, Edge, Firefox, Brave) do not have Apple permissions to trigger the iOS configuration profile installer.

⚠️

How to Remove DNS / Reset to Default

If you ever need to restore your iPhone or iPad back to factory network defaults, follow these simple steps:

  1. For Wi-Fi Manual DNS: Go to Settings > Wi-Fi, tap the blue ⓘ next to your network, tap Configure DNS, and select Automatic. Tap Save in the top-right corner.
  2. For DNS Profile: Go to Settings > General > VPN & Device Management, select the YourBrand Gaming DNS Profile, and tap Remove Profile. Confirm with your passcode.
  3. Once removed, your device will immediately return to your ISP's original DNS settings without any restart needed.
